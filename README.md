# Beak

Beak is a modern, responsive social media platform designed to capture the core features and fast-paced interaction of Twitter/X. It allows users to post short updates ("Chirps"), engage with content through likes and reposts, and explore live trending hashtags.

---

## Features

- **Chirping:** Post short-form text updates and thoughts.
- **Timeline & Feed:** Real-time updates showcasing community activity and trending content.
- **Engagement:** Full support for liking, reposting, and interacting with Chirps.
- **Trending Hashtags:** Automated extraction and aggregation of popular topics and hashtags across the platform.
- **Responsive UI:** Clean, modern interface designed with Tailwind CSS for mobile and desktop screens.

---

## Tech Stack

- **Framework:** [Next.js](https://nextjs.org/)
- **Styling:** [Tailwind CSS](https://tailwindcss.com/)
- **Language:** TypeScript
